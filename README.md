One line, under 200 characters: a one-star review written by a house cat
about its human. The human stares at a glowing box all day and calls it
work — and the cat, having sat on the keyboard exactly once, got called
unprofessional. Deadpan review shape, specific complaint (the laptop
keyboard), feline voice throughout, sting in the last few words.

## Run it

```sh
node main.ts
```

The program writes the review to `/output/entry.txt` — one line, 130
characters, byte-identical on every run: no network, no randomness, no
clock.

## The review

> One star. The human stares at a glowing box all day and calls it work. I sat on the keyboard once and he called ME unprofessional.
